# Shqip Quest — Question authoring quality rules

Use this checklist whenever adding or editing lessons.

1. **Don't give the answer in the question.** If the answer is “Grandmother”, the prompt must not say “Find the image marked Grandmother”.
2. **Don't show English translations beside picture options.** The learner must interpret the illustration, not match a copied English label. Display “Picture A/B/C”, while retaining non-revealing descriptive text for accessibility.
3. **Don't include English glosses in picture prompts.** Prefer “Which picture best illustrates ‘Gjyshja’?” over “Which picture means ‘Gjyshja’ (grandmother)?”.
4. **Listening questions must not show the target spoken word in text before audio playback.** If audio is missing, a text-based fallback may provide the Albanian word, but the options should remain English meanings.
5. **English-to-Albanian translation prompts must have Albanian answers; Albanian-to-English prompts must have English answers.** A sentence completion task may show its target phrase in English while asking the learner to arrange Albanian tokens.
6. **Check every distractor.** Exactly one option should be defensibly correct (unless intentionally multi-select). Avoid duplicate meanings and accidental synonyms.
7. **Keep each question ID and its index stable after publication** so that stored mastery and completed progress retain their meaning. For significant changes to the learning objective, append a new question instead.
8. **Randomise answer order, not the answer key.** Keep the same option order until feedback appears, and preserve the mapping between picture choices, descriptions and their original answer values.
9. **Test with and without audio.** Offline or missing-audio fallbacks should remain answerable and must never reveal the answer before a selection.
10. **Run an all-question audit before each release.** Review prompts, options, visible captions, accessibility labels and feedback screens. Include a short test summary with the release.

The above checks apply to all lesson quizzes, unit challenges, Personal Review and standalone listening activities.
